# Algoritmos 41 a 50 em Kotlin

Este repositório contém a conversão dos algoritmos 41 a 50 do livro de Anita Lopes e Guto Garcia para a linguagem Kotlin.

Os exercícios foram desenvolvidos no IntelliJ IDEA, com o objetivo de praticar lógica de programação e conhecer melhor os recursos da linguagem Kotlin.

## Algoritmos desenvolvidos

- **Algoritmo 41:** Calcula a média ponderada de quatro números.
- **Algoritmo 42:** Calcula funções trigonométricas a partir de um ângulo informado.
- **Algoritmo 43:** Calcula o logaritmo de um número na base 10.
- **Algoritmo 44:** Calcula o logaritmo de um número em uma base informada.
- **Algoritmo 45:** Calcula o quadrado e a raiz quadrada de um número.
- **Algoritmo 46:** Calcula o novo saldo após um reajuste de 1%.
- **Algoritmo 47:** Inverte a ordem dos algarismos de um número de três dígitos.
- **Algoritmo 48:** Calcula o valor do consumo de energia elétrica e aplica um desconto de 10%.
- **Algoritmo 49:** Realiza operações com os caracteres de um nome.
- **Algoritmo 50:** Calcula o perímetro, a área e a diagonal de um retângulo.

## Comentários sobre os exercícios

Neste bloco, pratiquei principalmente operações matemáticas e manipulação de strings.

Alguns exercícios exigiram o uso de funções da biblioteca `kotlin.math`, como `sqrt()`, `pow()`, `sin()` e `cos()`. Também trabalhei com funções de strings, como `first()`, `last()`, `take()` e `drop()`.

Uma das coisas que observei durante os testes foi que o tipo `Double` pode apresentar resultados com várias casas decimais. Também aprendi que, ao utilizar `toDouble()`, os números decimais precisam ser digitados com ponto.

Todos os algoritmos foram executados e testados individualmente.

## Tecnologias utilizadas

- Kotlin
- IntelliJ IDEA
- JDK

## Organização

Os arquivos estão organizados individualmente, de `Algoritmo41.kt` até `Algoritmo50.kt`, dentro da pasta `src/main/kotlin`.
